# Тобольск: тогда и сейчас

Сайт-игра к индивидуальному проекту «Закрыть, снести или вернуть: архитектурное наследие Тобольска XVIII–XIX веков в XX - начале XXI века по данным повторной фотосъёмки» (XII музейная конференция «Невиданная Отчизна», 2026).

Игрок выбирает постройку на плане центра Тобольска, смотрит на архивный снимок и угадывает, что с ней стало, а потом сравнивает со снимком 2026 года.

Открыть: https://urijkoselev2335-del.github.io/tobolsk/

- Автор проекта: Юрий Кошелев. Код сайта написан с помощью ИИ по заданию автора.
- Снимки 2026 года: Юрий Кошелев, 8 ноября 2026 г.
- Архивные снимки: PastVu, Библиотека Конгресса США (С. М. Прокудин-Горский). Подписи — на карточке каждой постройки.
